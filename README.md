# MEZZZEO.github.io

Статическая страница портфолио. Для GitHub Pages достаточно загрузить содержимое этой папки в репозиторий `MEZZZEO.github.io` и включить Pages из ветки `main`, папка `/root`.

Изображения видео берутся напрямую с YouTube по публичным thumbnail-URL; остальная страница не требует сборки или зависимостей.
